## ✨ What's different from the original

| | |
|---|---|
| 💽 **Any USB drive** | FAT32, exFAT or NTFS, exactly as it is. No profile, no permission step. |
| 🎯 **Starts from Game Vault** | Pick a game in Game Vault and it starts here; quit and you are back in Game Vault. |
| 📦 **Your add-ons** | Title updates and downloadable content next to your games are found and used. |
| 🗂️ **Many game formats** | Disc images, Games on Demand and Xbox Live Arcade games, including `.zar` files. |
| ⚙️ **Per-game settings** | Set up each 360 game from Game Vault. |

## 🚀 Getting started

The easy way: install **[Game Vault](https://github.com/skitzellez/xbox-game-vault)**. Its setup installs this emulator, and Game Vault
offers each new version on its update screen (press **RT**).

By hand: download `XeniaForGameVault_<version>_x64.appx` from [Releases](https://github.com/skitzellez/Xenia-GameVault/releases/latest) and add it in
Device Portal (**My games & apps → Add**), with the dependencies it asks for.

## 🎮 The Game Vault family

Game Vault is one launcher plus emulators built to work with it. **Install [Game Vault](https://github.com/skitzellez/xbox-game-vault) and it sets these up for you**; press **RT** in Game Vault to update them all.

**Apps**

| Project | What it is | Runs on |
|---|---|---|
| [Game Vault](https://github.com/skitzellez/xbox-game-vault) | The launcher: plug in a USB drive, pick a game, play. Sets up everything below by itself. | Xbox Series X&#124;S |

Xenia Canary is an experimental fork of the Xenia emulator. For more information, see the
[Xenia Canary wiki](https://github.com/xenia-canary/xenia-canary/wiki).

Come Join the Xbox Emulation Hub Discord server for help, support and general dissusion: https://discord.gg/WCmxvvxHqu
For developer chat join `#dev` but stay on topic. Lurking is not only fine, but encouraged!
Please check the [FAQ](https://github.com/xenia-canary/xenia-canary/wiki/FAQ) page before asking questions.
We've got jobs/lives/etc, so don't expect instant answers.

Discussing illegal activities will get you banned.

## Contributors Wanted!

Have some spare time, know advanced C++, and want to write an emulator?
Contribute! There's a ton of work that needs to be done, a lot of which
is wide open greenfield fun.

**For general rules and guidelines please see [CONTRIBUTING.md](.github/CONTRIBUTING.md).**

Fixes and optimizations are always welcome (please!), but in addition to
that there are some major work areas still untouched:

* Help work through [missing functionality/bugs in games](https://github.com/xenia-canary/xenia-canary/labels/compat)
* Reduce the size of Xenia's [huge log files](https://github.com/xenia-canary/xenia-canary/issues/1526)
* Skilled with Linux? A strong contributor is needed to [help with porting](https://github.com/xenia-canary/xenia-canary/labels/platform-linux)

See more projects [good for contributors](https://github.com/xenia-canary/xenia-canary/labels/good%20first%20issue). It's a good idea to ask on Discord and check the issues page before beginning work on
something.

## Disclaimer

The goal of this project is to experiment, research, and educate on the topic
of emulation of modern devices and operating systems. **It is not for enabling
illegal activity**. All information is obtained via reverse engineering of
legally purchased devices and games and information made public on the internet
(you'd be surprised what's indexed on Google...).
